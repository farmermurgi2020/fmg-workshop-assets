# FMG Workshop assets

Images used on the Steam Workshop pages of the FMG Project Zomboid mods.

## FMG-RNGesus Gem Codex
`rngesus/index.html` is the Gem Codex page (every quirk, curse and skill as its in-game card), served by GitHub Pages at
https://farmermurgi2020.github.io/fmg-workshop-assets/rngesus/. It is generated by `tools/codex/build.js` in the
FMG-RNGesus repo; don't edit it here. `rngesus-codex-button.gif` is its Workshop button.
